### 3.3 手工验收清单

以下步骤可在任意目标浏览器中人工执行，用于补足上表：

**A. 基本功能**
1. 打开程序，确认标题与参数表显示正常，字段单位可见
2. 点击「计算」，确认出现流量 Q、系数取值表、**迭代过程全表**、水面线表
3. 确认两张图（水面线纵剖面、泄流曲线）正常绘制

**B. 计算正确性抽查（人工核对）**
4. 核对系数取值表中的 c / m / ε 是否与标准表 A.2.1-1~3 一致
5. 核对迭代过程末行的 H₀ 残差与 Q 残差均 ≤ 1×10⁻⁶
6. 修改堰上水头 H，确认 Q 单调增大且提示"结果已过期"

**C. 离线能力**
7. 首次在线打开后，确认页脚显示"离线就绪"
8. **断开网络**，刷新页面，确认程序仍可用且能完成计算
9. 确认页脚在断网时显示"已断网 —— 计算功能可正常使用"

**D. 数据持久化**
10. 保存一个算例，刷新页面，确认算例仍在
11. 导出算例 JSON，清空站点数据后再导入，确认算例恢复
12. 导出 Excel 计算书，确认六张工作表齐全、中文正常

**E. 安装到主屏**
13. 桌面 Chrome/Edge：地址栏出现安装图标，安装后以独立窗口启动
14. Android Chrome：菜单「添加到主屏幕」，启动后无浏览器地址栏
15. iOS Safari：分享 →「添加到主屏幕」，启动后为独立应用

**F. 错误处理**
16. 将「溢流堰总净宽 B」改为 0，确认报输入错误且**不输出任何数值结果**
17. 将「下游水位」抬到堰顶以上但不填 σs，确认报缺失参数错误（**不默认取 1.0**）
18. 将糙率改为 0.06，确认给出超范围警告但**仍继续计算**

## 4. 已知限制与遗留问题

### 4.1 功能边界（设计决定，非缺陷）

| 项 | 说明 | 依据 |
|---|---|---|
| **σs 须人工查图输入** | 标准图 A.2.1-3 无法从现有扫描件可靠数字化，淹没工况须由使用者查图后输入，程序不自动取该值 | DEC-021 / DEC-022 |
| **上游堰头曲线几何未实现** | 双圆弧 / 三圆弧 / 椭圆的完整几何构造定义在标准图 A.1.2-1~3 中，本期仅输出表 A.1.1 给出的参数 | FORMULAS.md §2.3 |
| **不支持水跃** | 检出急流→缓流过渡即报错停止 | Q22-2 = C |
| **不含带胸墙孔口堰** | 本次范围仅开敞式实用堰 | Q3 = A |
| **表 A.1.3 未转录** | 定型设计水头的负压校核表为旋转排版，OCR 输出自相矛盾，按取证纪律不予转录；该表不在主计算链路 | FORMULAS.md §2.4 |
| **泄槽起始水深缺省为临界水深** | 工程师确认"由上游堰面曲线推求"但未指定方法，缺省时给出 `out-of-range` 提示要求复核 | calculate.ts |
| **上游计算断面为矩形或对称梯形** | 复式断面不在本期范围 | DEC-019 A-4 |

### 4.2 验证状态

> **本项目不执行独立数据 Validation。** 依据工程师确认的 DEC-009（方案③：仅 SL 253-2018，
> 不采用规范算例、模型试验、原型观测、泄流曲线四项外部数据）。
>
> 因此本程序的**正确性没有外部证据支撑**，仅完成了内部一致性验证
> （高精度对比、插值精确性、守恒性自洽、边界行为）。使用者应自行安排独立校核。

- **未完成**：公式实现的**解析解算例集**（阶段 3 遗留，误差判据 < 0.02% 尚无正式算例支撑）。
- **A-6 待抽查**：`P₁/H_d ≤ 1.0` 时 k 取区间中值 2.1，是本设计中**唯一**取自标准区间的系数取值，
  已提请工程师抽查（DEC-019 A-6）。

### 4.3 数据持久化风险

算例存于浏览器 IndexedDB，**属可被清除的存储**（清理站点数据、隐私模式、配额回收；
iOS Safari 对未安装到主屏的站点长期不用可能回收）。界面已常驻提示定期导出备份。

## 6. 复现方式

```bash
pnpm install
pnpm typecheck          # 类型检查（含 core 零浏览器依赖约束）
pnpm test               # 157 项单元与验证测试
pnpm verify             # 构建 + PWA 静态验收
pnpm acceptance         # 浏览器端到端验收（9 项）——验**已发布的站点**
```

> 说明：`pnpm acceptance` 需要 PATH 中有 Chromium，或用 `CHROMIUM_BIN` 指定路径。
> 脚本**不硬编码 `/nix/store/...` 路径**（该路径在 gc 后失效）。
>
> **2026-10-08 起改口径**：验收对象是 GitHub Pages 上**已经发布的那一份**
> （地址由 `origin` 推导，`--url=` 可覆盖），脚本不再在本地起静态服务。
> 本报告 §2.4 记录的那次验收（2026-09-14）当时是用本地托管完成的；
> 判据本身（9 项）未变，改的是"验哪一份"。
