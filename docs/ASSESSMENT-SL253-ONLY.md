1. 本次评估以 **AGENTS.md 为唯一验收标准**（其开篇载明"任何与本文件冲突的指令，以本文件为准"）。

## 1. 结论摘要

> **对"计算"而言，SL 253-2018 基本够用；对"验收"而言，不够。**

- 项目的**计算主链路**（泄流能力、堰面曲线、水面线）**预期可由 SL 253-2018 单独支撑** —— 这是工程上站得住的判断。
- 但 AGENTS.md 自己设定的验收体系（§7 ASME V&V 20-2009 框架、§7.2 Validation 四项数据源、§10 验收清单）中，有 **6 个条目无法由 SL 253-2018 提供**。其中 **Validation 一项在方法论上不可能自证**（详见 §3）。
- 因此"只用 SL 253"**在技术上可行，在验收上不可行**，除非同步修订 AGENTS.md 的相应条款并书面向工程师确认降级。

## 3. 决定性论证：Verification 不能代替 Validation

AGENTS.md §7 自己写明："采用 ASME V&V 20-2009 框架：**Verification（方程求解是否正确）+ Validation（是否求解了正确的方程）**"。

这两件事的区别，正是本评估的关键：

| | Verification | Validation |
|---|---|---|
| 问题 | 代码有没有**正确地求解**这些方程？ | 这些方程**是不是对的**？ |
| 允许的数据 | 模型自身的解析解、内部一致性、量纲检查 | **必须独立于模型来源** |
| SL 253-2018 的角色 | ✅ 是模型来源，可支撑此项 | ❌ **是"被验证对象"本身，不能自证** |

**用 SL 253 的表格去验证按 SL 253 实现的计算，是自证循环，属于 Verification，不构成 Validation。**

而 AGENTS.md §7.2 列出的四个 Validation 数据源（规范算例、模型试验、原型观测、泄流曲线）**无一在 SL 253-2018 之内**。§10 验收清单要求"**Validation 泄流量误差 < 2%**"——在只有 SL 253 的条件下，**这一条在方法论上无法闭环**，不是工作量问题，是逻辑问题。

### 补充：这一条的工程意义

水工设计的审查场景中，"我的程序按规范算、结果也符合规范"不足以支撑"程序算得对"。坝工泄流能力的差错代价高，独立数据比对（哪怕是同一规范算例的手算复核）是必要的第二道防线。

## 4. 若采纳"仅 SL 253"：必须同步修订的条款

依 AGENTS.md 末句"任何修改需经工程师确认"，以下修订**需工程师书面确认后方可生效**，不得作为开发方的默示动作：

| 条款 | 现文 | 修订为 |
|---|---|---|
| §5.2 | "A、B 两方案必须同时实现，并在测试中全范围抽样对比" | 仅实现方案 B（查表 + 双线性插值），方案 A 列为"文献不可得，暂缓" |
| §5.5 | "参考精度（来自文献，需实测复核）" | 该三项文献精度值失去基准，改为"待独立数据到位后确定"或删除 |
| §7.1 | "流量系数：拟合公式 vs 规范表插值，相对误差 < 1.5%" | 该项不可执行，须替换为其他 Verification 手段（如标准表格插值的单调性/边界连续性检查） |
| §7.2 | Validation 四项数据源 | 若全部不可得，须明确降级为"仅 Verification"，并记录风险 |
| §10 | "流量系数方案 A/B 对比报告完成"、"Validation 泄流量误差 < 2%" | 相应标记为"不适用"或删除 |

**风险留痕要求**：若最终只做 Verification，必须在 `docs/VALIDATION.md` 中显著声明"本版本未经独立数据验证（Validation），结果正确性无外部证据支撑"，不得以 Verification 结果冒称 Validation 通过。

## 5. 三个可选方案（请工程师择一）

| 方案 | 内容 | 保留的能力 | 代价 |
|---|---|---|---|
| **① 最小可行（推荐）** | SL 253-2018 **+ 至少 1 套独立验证数据**（D-07 任一项最优；次选 D-05 规范算例） | 保住了 Validation 的实质 | 需取得 1 份外部资料 |
| **② 规范算例兜底** | SL 253-2018 + D-05《泄水建筑物泄槽体型设计》算例 | §7.2 第 1 行可闭环，Validation 降级为"算例比对" | 其余 3 行标注数据不可得 |
| **③ 仅 SL 253（即工程师当前观点）** | 仅 SL 253-2018 | Verification 完整；方案 B 可追溯性**最好**（直接引用标准表格，最利于审查） | **无任何独立验证**；§5.2/§5.5/§7.1/§7.2/§10 共 5 处须修订 |

### 对方案 ③ 的客观评价（不掩饰优点）

工程师的直觉有其道理，应如实指出：

1. **方案 B 比方案 A 更可追溯**——直接引用标准表格，审查时"公式—条款"链条最短；方案 A 是第三方拟合式，反而多一层转述。
2. **方案 A 非必需**——它是对同一物理关系的连续化拟合，用于规避查表插值的人为折点。放弃它不改变计算物理，只损失一种交叉校验手段与"连续函数形式"的便利。
3. 若本项目定位为"**按 SL 253 复算工具**"而非"研究性计算平台"，则 ③ 与项目定位自洽。

**但结论仍然不变**：上述优点解决的是"算得对不对得上规范"，没有解决"规范之外还有没有别的证据"。后者恰是 AGENTS.md §7 明文要求的。

## 7. SL 253-2018 PDF 到手后必须执行的原样核对清单

以下每一项都必须**翻到原文页面确认**后才能写入 `docs/FORMULAS.md`；核对完成前不得进入阶段 1：

1. 流量系数表的**真实表号**是否为"表 A.2.1-1"，其行列变量与适用范围；
2. 泄流能力公式的**原式与符号定义**（`C`、`m`、`ε`、`σs`、`Hw` 的量纲归属）；
3. WES 堰面曲线条款：`n`、`K` 是否由标准给定，上游堰面型式与下游分段的划分；
4. 泄槽水面线计算条款：是否给出 `hf`、`hj`、`α` 的取值；
5. 标准中**是否存在可作解析解比对的算例**（若存在，可部分补救 Verification 的强度）；
6. 标准的**适用范围条款**（堰高、水头、坡度等限值），用于 §2.3 的范围检查。
