## ⚠️ 强制声明：本版本未经独立数据验证

> **本程序当前版本的设计范围不含独立的 Validation（确认）环节。**
> 依据工程师 2026-09-14 的决策（技术依据仅采用 SL 253-2018 单一来源，见
> `docs/DECISIONS.md` DEC-009），本项目**不进行**基于独立数据的 Validation
> ——即不使用规范算例、模型试验、原型观测或实测泄流曲线作为比对基准。
>
> **因此：本程序的计算结果正确性没有外部证据支撑。**
> 程序所能保证的仅为 Verification（方程求解是否正确），不能保证模型本身的适用性
> （是否求解了正确的方程）。**不得以 Verification 结果冒称 Validation 通过。**
>
> 使用者在将本程序结果用于设计、复核或审查时，**应自行安排独立校核**。

## 1. Verification（代码验证）

### 0. 已声明的可靠性限制：σs（淹没系数）为人工查图输入，非程序计算

图 A.2.1-3 经 6 轮图像分析判定**无法从现有扫描件可靠数字化**
（线条最长连续段仅占图幅宽度约 46%，无可用作坐标标定的连续图框线；红色水印压在最密集区。
详见 `DECISIONS.md` DEC-021）。因此：

- 下游水位**不高于**堰顶（`hs ≤ 0`）时，程序判定为不淹没并取 **σs = 1.0**（有标准依据：曲线族在该处收敛于 1.00）；
- 下游水位**高于**堰顶（`hs > 0`）时，**σs 由使用者按标准图 A.2.1-3 查图输入**，
  程序仅做范围校验（`0.20 ≤ σs ≤ 1.0`）与一致性校验。**程序不对该值的准确性负责。**

> **使用者须知**：淹没工况下，σs 的准确性完全取决于人工查图的准确性。
> 程序不会、也无法对该值作独立校核。程序**不默认取 1.0**，以避免静默高估泄流量。

### 1.2 阶段 3 实测明细

**1.2.1 浮点精度（decimal.js 40 位对比）**

| 项 | 实测 |
|---|---|
| 泄流量 Q 链式计算（单点） | ✅ 偏差 < 0.01% |
| 泄流量 Q 链式计算（H 扫描 1.0~6.0，11 点） | ✅ 全部 < 0.01% |
| 幂曲线 y(x)（6 个非整洁小数点） | ✅ 偏差 < 0.01% |
| 表 A.2.1-1 双线性插值 vs Decimal 同权重计算 | ✅ 相对偏差 < 1×10⁻¹² |

**结论**：双精度链式计算相对 40 位十进制高精度结果的偏差**远低于通过标准**，
未发现任何中间量被提前舍入。

**1.2.2 浮点边界用例**

| 用例 | 结果 |
|---|---|
| `H₀/H_d` 取 `.1/.2/.3` 结尾的表内格点 | ✅ **精确等于表值**（`toBe` 位比较，非容差） |
| `P₁/H_d` = 1.0 与 1.33 关键节点 | ✅ 精确 |
| `.5` 行 / 列中点插值 | ✅ 与十进制精确值偏差 < 1×10⁻¹⁵ |
| 幂曲线反函数 x→y→x（10 个非整洁小数） | ✅ 相对误差 < 1×10⁻¹² |
| x = 0 处 | ✅ 精确为 0（非 −0，非 NaN） |
| 极小 / 极大水深（1e−6 ~ 1e6 m） | ✅ 全部有限值 |

**1.2.3 迭代收敛与数值稳定性**

| 项 | 结果 |
|---|---|
| 收敛时 H₀ 与 Q 的相对残差 | ✅ 均 ≤ 1×10⁻⁶ |
| 中间量是否被提前舍入 | ✅ 未舍入（保留双精度全位数） |
| 发散拦截 | ✅ 报 `failure`，**不泄漏 NaN / Infinity** |
| 陡坡 S2 型水面线趋势 | ✅ 沿程趋近正常水深 |
