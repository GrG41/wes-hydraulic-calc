### ✅ 项 4 —— 泄槽水力计算（印张页 53，PDF p.60）

**A.3.1**　泄槽水面线应根据 **能量方程，用分段求和法** 计算。

```
Δl₁₋₂ = [ (h₂cosθ + α₂v₂²/(2g)) − (h₁cosθ + α₁v₁²/(2g)) ] / ( i − J̄ )    (A.3.1-1)
J̄  = n² · v̄² / R̄^(4/3)                                                    (A.3.1-2)
v̄  = (v₁ + v₂)/2                                                          (A.3.1-3)
R̄  = (R₁ + R₂)/2                                                          (A.3.1-4)
```

**式中（照录）**：

| 符号 | 原文定义 |
|---|---|
| Δl₁₋₂ | 分段长度，m |
| h₁、h₂ | 分段始、末断面水深，m |
| v₁、v₂ | 分段始、末断面平均流速，m/s |
| **α₁、α₂** | **流速分布不均匀系数，取 1.05** |
| θ | 泄槽底坡角度，(°) |
| i | 泄槽底坡，i = sinθ；当 θ 较小时，i ≈ tanθ |
| J̄ | 分段内平均摩阻坡降 |
| **n** | **泄槽槽身糙率系数，查附录表 A.8** |
| v̄ | 分段平均流速，m/s |
| R̄ | 分段平均水力半径，m |

## 3. 与 AGENTS.md 的差异清单（**本次核对最重要产出**）

### D-1　`C` 不是"单位系数"，而是 **c = 上游堰坡影响修正系数**
- **AGENTS.md §5.1**：`C 单位系数（SI 制下取值）— [待确认]`
- **标准 A.2.1-1**：`Q = c · m · ε · σs · B · √(2g) · H₀^(3/2)`，**c 为上游堰坡影响修正系数**：上游堰面**铅直时 c = 1.0**；**倾斜时查表 A.2.1-2**。
- **风险**：若按"单位系数 = 1"实现，在**倾斜上游堰面 + 低 P₁/H_d** 工况将漏乘 c，**最大偏差约 +2.1%**（3:3 坡度、P₁/H_d = 0.3 时 c = 1.021）。铅直堰面工况下恰好 c = 1.0，**该错误不会暴露**——属隐蔽缺陷。

### D-2　主公式的水头是 **H₀（总水头）**，不是 Hw
- **AGENTS.md §5.1**：`Q = … · Hw^(3/2)`，并另列 `H₀ = Hw + α·v₀²/(2g)` 的迭代
- **标准 A.2.1-1**：主公式用 **H₀^(3/2)**；**A.2.1-3** 定义 **`H₀ = H + v²/(2g)`**（`H` 为堰上水头、`v` 为行进流速，**式中无动能修正系数 α**）〔600 DPI 复核〕
- **结论**：AGENTS.md §5.1 的"行进流速水头迭代"要求方向正确，但**主公式的水头项应改为 H₀**；且 (A.2.1-3) **不含 α**，AGENTS.md 的 `α·v₀²/(2g)` 中的 α 在标准中无对应物。

### D-3　`ε` 有明确公式（AGENTS.md 原标 [待确认]）
`ε = 1 − 0.2[ζ_k + (n−1)ζ₀]·H₀/(n·b)`，**分子用 H₀（与主公式同一总水头）**；适用于 **H₀/b ≤ 1.0**，超过时 **H₀/b 取 1.0**。
〔**勘误**：本文档早期版本曾误记为"分子用 Hw"，已于 600 DPI 复核后更正，见 §5〕

### D-4　`σs` 是**图**（图 A.2.1-3），不是表
- **AGENTS.md §5.1**：`σs 淹没系数 — [待确认]`
- **标准**：`σs 淹没系数，可查 图 A.2.1-3`（横轴 P₁/H_d，纵轴 hs/H₀，曲线族 σs = 0.20 / 0.50 / 0.60 / 0.70 / 0.80 / 0.85 / 0.90 / 0.92 / 0.94 / 0.96 / 0.98 / 1.00）
- **工程影响**：图为曲线族，**无法直接"查表"**。实现须选择：① 图表数字化为数值表 + 插值；② 拟合曲面；③ 人工读图输入。**这属于 AGENTS.md §9.1"需在多个技术方案间取舍"，须工程师裁定**，不得由开发方自行拟定。

### D-5　`n`、`K` 随**上游堰坡度**变化，非常数
- **AGENTS.md §5.3**："常见值 n=1.85, K=2.0，但必须由工程师依据标准确认"
- **标准表 A.1.1**：`3:0 → k=2.000, n=1.850`；`3:1 → 1.936 / 1.836`；`3:2 → 1.939 / 1.810`；`3:3 → 1.873 / 1.776`
- **结论**：AGENTS.md 的 n=1.85 / K=2.0 **对应"上游堰面铅直（3:0）"工况**，与标准一致 ✅；但对倾斜上游堰面必须改用对应值。

### D-6　`hf` / `hj` / `α` 的结构与 AGENTS.md §5.4 不一致
- **AGENTS.md §5.4**：能量方程含 `hf + hj` 独立损失项；`α₁、α₂` 标为 [待确认]
- **标准 A.3.1-1**：以 **`i − J̄`** 表达损失，**`J̄ = n²v̄²/R̄^(4/3)`（曼宁式摩阻坡降）**；**公式中无独立局部损失项 hj**；**α₁ = α₂ = 1.05（定值）**
- **结论**：§5.4 的"hf 与 hj 系数取值"这一待确认项**在标准中不存在对应物**：hf 已内含于 J̄，hj 未在 A.3.1 出现。需工程师确认按标准结构实现（`i − J̄`）。

### D-7　补充发现：标准对**驼峰堰**给出了幂函数拟合式（印张页 52，PDF p.60 页首）

```
A.2.4-1（a 型）: P₁/H₀ ≤ 0.24 时 m = 0.385 + 0.171(P₁/H₀)^0.657
                 P₁/H₀ > 0.24 时 m = 0.414(P₁/H₀)^-0.0652
A.2.4-2（b 型）: P₁/H₀ ≤ 0.34 时 m = 0.385 + 0.224(P₁/H₀)^0.634
                 P₁/H₀ > 0.34 时 m = 0.452(P₁/H₀)^-0.032
```

> **意义**：标准自身对**驼峰堰**采用幂函数系数式，对 **WES 实用堰**则采用**查表**。这为"是否需要自建 WES 拟合式"提供了一个**标准内的先例参照**。但**不得据此自行拟合 WES**——那仍属 §9.3 禁止的自行假设。
