### DEC-021　σs 数字化：经 6 轮图像分析判定本扫描件不可行，改走替代路径
- **日期**：2026-09-14
- **背景**：工程师批准后实施图 A.2.1-3 的数字化（DEC-019 / DEC-020）
- **结论**：**无法从 `reference/standards/SL253-2018.pdf` 可靠地数字化该图。**

#### 证据链（全部可复现）

| # | 方法 | 结果 |
|---|---|---|
| 1 | 300 DPI 全页 PPM；按 `R−(G+B)/2 > 35` 剔除红色水印（占 3.01%） | 墨迹仅 1.21%；无一条 >60% 页宽的长线 |
| 2 | 灰度直方图 | 98.19% 像素落在 230–256，线条极细 |
| 3 | 限定图内 x∈[200,1400]，阈值放宽至 235（非白即墨） | 行最大覆盖仅 **44.4%**，仍无长线 |
| 4 | **逐行/逐列最长连续墨迹段**（决定性判据） | 横向最长 **366 px**、纵向 **132 px**；而图幅约 **797 × 1100 px**（300 DPI） |
| 5 | `pdfimages -list` | 内嵌图像原生 **600 DPI（7040×4912，RGB JPEG）** —— 先前 300 DPI **只用了一半分辨率** |
| 6 | 按原生 600 DPI 重做最长段检测 | 横向最长 **731 px**、纵向 **254 px**；图幅约 **1594 × 2200 px**（600 DPI） |

#### 判定

即使采用**原生 600 DPI**，线条最长连续段仍仅占图幅宽度的约 **46%** ——
**扫描件的线划是断裂的，不存在可用于坐标标定的连续图框线**。
加之红色水印覆盖 x∈[316,1080]、y∈[1297,1994]（300 DPI 坐标），恰压在最密集的区域。

因此在 **0.25 × 0.05 网格（15 × 21 = 315 节点）** 上给出可信 σs 值**不可行**。
强行输出将违反项目禁止行为（不得编造系数值、不得制造虚假精度）。

#### 替代路径（待工程师选择）

- **路径 A（推荐，立即可行）**　程序**自动判定是否自由出流**：当 `hs/H₀` 低于图的下边界（未淹没）时
  直接取 **σs = 1.0**（有标准依据——曲线族在该处收敛于 1.00）；**仅当判定为淹没时**，
  由使用者在界面按标准图人工读图输入 σs，程序做合理性校验（`0.20 ≤ σs ≤ 1.0`，且随淹没度单调不增）。
  符合归纳取向 **P3**（工程判断交使用者），不制造虚假精度。**溢流堰多数工况不淹没**，实际影响有限。
- **路径 B（质量最优）**　由工程师提供该图的**清晰版本**（清华大学《水力学》，或美国陆军工程兵团
  《水力设计准则》第一卷——条文说明印张页 182 已指明这两个来源），开发方据此数字化。
- **路径 C（不推荐）**　继续编写抗断裂的曲线追踪算法。技术上可做，但**正确性无法验证**（无真值可比），
  且水印覆盖区无论如何无法恢复。

### DEC-022　σs 取值：采用路径 A（自动判定自由出流 + 淹没时人工查图），路径 B 并行

#### 一、σs 取值逻辑（路径 A）

```
① 计算  hs = 下游水位 − 堰顶高程
② 若 hs ≤ 0（下游水位不高于堰顶）：
       判定为不淹没 → σs = 1.0        （有标准依据：曲线族在该处收敛于 1.00）
③ 若 hs > 0（潜在淹没）：
       程序【不自动取值】。要求使用者按标准图 A.2.1-3 读取并输入 σs；
       界面同时显示查图坐标 P₂/H₀ 与 hs/H₀，便于定位；
       校验：0.20 ≤ σs ≤ 1.0，且 σs < 1.0 与 hs ≤ 0 不得同时出现。
④ 若 hs > 0 而使用者未输入 σs：
       判为【输入错误：缺参数】→ 拒绝计算。
       ⚠️ 不默认取 1.0 —— 否则会在真淹没工况下静默高估泄流量。
⑤ 计算书须标注 σs 的来源（"自动判定自由出流"或"人工查图输入"）及查图坐标。
```

#### 二、为什么这样定

| 考虑 | 处理 |
|---|---|
| 图 A.2.1-3 无法可靠数字化（DEC-021） | 不伪造数值，改由人工查图 |
| 归纳取向 **P3**（工程判断交使用者） | 淹没判定交使用者，程序只做校验 |
| 归纳取向 **P2**（超范围警告并继续） | 保留计算能力，不因缺表而整体停摆 |
| 归纳取向 **P5**（做不了的明确划界） | 明确划出"程序能自动判定的"与"必须人工查图的" |
| 安全 | hs > 0 时**不默认 1.0**，避免静默高估 Q |
| 实用性 | 溢流堰多数工况不淹没（hs ≤ 0），此时全自动，使用无感 |
