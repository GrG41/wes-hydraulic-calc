## 1. 对项目目标的理解

### 1.1 一句话理解

面向水工设计、复核、审查人员的**生产级**工程计算软件：输入必要参数后，按我国溢洪道设计规范计算 WES 型实用堰的**泄流能力**与**堰流水面线**，并把**可追溯的计算过程**（中间变量、迭代过程、系数来源、适用范围检查）完整呈现与导出。

### 1.2 五项核心输出（AGENTS.md §1.1）

| 序号 | 输出 | 我的理解 | 落地位置 |
|---|---|---|---|
| 1 | 泄流能力计算结果 | Q 及 Q–H 关系（泄流曲线） | `src/core/formulas/discharge.ts`、`coefficient.ts` |
| 2 | 堰流水面线计算结果 | 沿程水深/水位/流速，分段推算 | `src/core/formulas/waterProfile.ts` |
| 3 | 完整计算过程与中间变量 | 符号 → 代入值 → 中间结果 → 迭代残差 → 系数来源标注；用于**错误检查**（人工验算） | 核心层返回结构化过程数据，UI/计算书只做格式化 |
| 4 | 可修改参数再次试算 | 保留上次参数、快速回算 | 状态层 + 表单 |
| 5 | 可导出的计算书 | 可编辑格式、公式编号可追溯、单位完整 | `src/export/` |

### 1.3 项目性质

工程计算软件，**非演示 Demo**，需达到生产环境可用标准。理解其含义：数值结果必须可复核、可追溯、可复现；精度与适用范围的边界必须显式声明；不得为了"跑通"而静默放宽。

### 1.4 非目标（本期不做，AGENTS.md §1.2）

闸门局部开启工况 / 掺气、空化、消能工计算 / 三维流场与 CFD / 多方案自动优化。

> 注：非目标中的"掺气"，与 §5.4 中"是否考虑掺气（本期倾向不考虑）"一致；仍按 §5.4 登记为待确认项（A-17）。

### 1.5 交付形态

PWA（主）；Electron / Tauri 打包为阶段 7（可选、次）。

## 2. 对强制性约束（§2）的理解与落地方式

| 条款 | 我的理解 | 计划落地方式（阶段 2 起） | 可验证性 |
|---|---|---|---|
| §2.1 公式可追溯 | 每条公式在代码注释标注"标准编号 + 条款/附录/表号" | 每个公式函数上方固定注释块：`来源 / 条款 / 原式 / 变量定义 / 适用域`；同步登记 `docs/FORMULAS.md` 三列对照表 | 评审时逐条比对 FORMULAS.md 与标准原文 |
| §2.2 不得编造标准条款 | 所有引用只能来自 §3 列出的文档；缺失即 `[待工程师确认]` + 提问 | 未获文件前，FORMULAS.md 中相应行只写占位与待确认编号，不写条款号 | 全仓库 grep 条款号，逐一对应到已收到的文件页 |
| §2.3 不得自行假设系数 | 经验系数、查表值、适用范围必须由工程师确认 | 系数集中于 `src/core/constants.ts`，每项带来源注释；未确认项**不写入代码**，用显式的"未确认即拒绝计算"路径占位 | 常数文件审计：每个数值都有来源标注 |
| §2.4 单位显式化 | 输入输出带单位；内部统一 SI（m, s, m³/s） | 类型层区分"带单位量"与"内部 SI 标量"；所有对外字段名与 UI 标签含单位；换算集中在单一边界函数 | 单元测试：单位换算往返一致性 |
| §2.5 中间过程可见 | 不得只输出最终结果 | 核心层返回 `steps[]`（符号、代入值、中间结果）与 `iterations[]`（每次迭代值、残差） | 测试断言 steps/iterations 非空且完整 |
| §2.6 数值精度 | 中间计算禁止提前舍入；容差 ≤ 1×10⁻⁶；仅展示层格式化 | 核心层全程 double（或按 B-06 决定的 decimal.js 路径），不 round；格式化仅存在于 UI/导出层 | 代码审查：core 层禁止 `toFixed`；grep 校验 |
| §2.7 离线优先 | 断网后全部计算功能可用 | 计算全部在客户端；SW 预缓存应用外壳；IndexedDB 本地持久化；无任何运行时网络依赖 | Playwright 离线用例（阶段 6） |
| §2.8 异常不崩溃 | 非法输入、超范围参数给出明确提示 | 核心层返回 Result 类型（成功/输入错误/超范围警告/计算失败），不抛未捕获异常；UI 顶层错误边界 | 边界与超范围测试集（阶段 3） |

### 2.1 禁止行为（§9.3）——我视为硬红线

不编造条款号或系数值；不用"通常/一般"替代标准依据；未确认公式前不编码计算逻辑；不为通过测试而放宽断言或跳过用例；不静默处理超范围输入；不只输出结果不输出过程。
