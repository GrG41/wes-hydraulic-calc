# 一、泄流能力

**出处：SL 253-2018 附录 A.2.1，印张页 46–47**

## 1.1 公式

> A.2.1　开敞式 WES 型实用堰的泄流能力按下列公式计算，**公式（A.2.1-2）适用于 H₀/b ≤ 1.0，
> 当 H₀/b > 1.0 时，H₀/b 仍取值 1.0**。

| 编号 | 公式 | 式号 | 印张页 |
|---|---|---|---|
| **F-1** | `Q = c · m · ε · σs · B · √(2g) · H₀^(3/2)` | A.2.1-1 | 46 |
| **F-2** | `ε = 1 − 0.2 [ ζk + (n−1) ζ₀ ] · H₀ / (n·b)` | A.2.1-2 | 46 |
| **F-3** | `H₀ = H + v² / (2g)` | A.2.1-3 | 46 |

> **注意**：F-3 中**不含动能修正系数**；`H` 为堰上水头，`v` 为行近流速。
> F-1 的水头项是**总水头 `H₀`**，不是堰上水头 `H`。
